SKYDZ DESIGNS
01 — EL PROYECTO

Una idea sencilla para un problema cotidiano.

Nuestros dispositivos contienen conversaciones, fotografías, documentos, cuentas y otra información que no siempre queremos que otras personas puedan ver.

01

¿Qué es FaceAway?

FaceAway es un proyecto de software enfocado en la privacidad visual. Su propósito es utilizar tecnología de detección para determinar cuándo el usuario está mirando la pantalla y reaccionar cuando deja de hacerlo.

02

¿Por qué existe?

Muchas veces dejamos nuestro teléfono desbloqueado mientras realizamos otra actividad. Durante ese momento, la información que aparece en pantalla puede quedar expuesta.

03

Nuestra propuesta

Crear una experiencia de privacidad automática, rápida y sencilla que pueda reaccionar al entorno sin exigir que el usuario bloquee manualmente la pantalla cada vez.

02 — CARACTERÍSTICAS

Diseñado alrededor de la privacidad.

FaceAway combina diferentes componentes de software para crear una experiencia enfocada en proteger la información visual del usuario.

👁

Detección visual

El sistema puede utilizar la cámara para identificar si existe un rostro frente al dispositivo.

🔒

Protección automática

Cuando se detecta que el usuario ya no está mirando, la aplicación puede proteger visualmente el contenido mostrado en pantalla.

⚡

Respuesta rápida

La propuesta busca que las acciones relacionadas con la privacidad ocurran de forma rápida y natural.

🛡

Pensado para el usuario

El objetivo principal es ofrecer protección sin convertir la privacidad en una tarea complicada.

03 — VISIÓN

La tecnología debe protegerte, no complicarte.

FaceAway nace de una pregunta sencilla: ¿qué pasaría si nuestro dispositivo pudiera reaccionar cuando nuestra atención ya no está sobre él?

A partir de esa idea se desarrolla una propuesta que combina privacidad, automatización y tecnología móvil para crear una experiencia diferente.
